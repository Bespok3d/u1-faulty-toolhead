# Changelog

## 0.1.1 (2026-08-16)

Faulty Toolhead 2 Bypass is now a stable plugin. Before, it only showed up in the store if you
had set your plugin channel to testing; now it shows for everyone. Nothing about the plugin itself
changed.

## 0.1.0

- First release. Ports faulty-toolhead profile 2 from the extended firmware to
  stock firmware as a declarative config include.
- Installed and running on a U1.
